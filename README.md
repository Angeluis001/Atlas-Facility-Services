# Atlas Facility Services

Sitio web corporativo de **Atlas Facility Services** — soluciones integrales en HVAC, eléctrico, plomería, pintura, mantenimiento general y seguridad electrónica.

## Stack

- HTML / CSS / JavaScript (estático)
- Listo para desplegar en [Vercel](https://vercel.com)

## Desarrollo local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
# Python
python -m http.server 8080

# Node
npx serve .
```

## Deploy en Vercel

1. Importa este repositorio en [vercel.com/new](https://vercel.com/new)
2. Framework Preset: **Other**
3. Build Command: *(vacío)*
4. Output Directory: `.` (raíz)
5. Deploy

## Contacto en el sitio

Actualiza email y teléfono en `index.html` (sección `#contacto`) antes de publicar en producción.
